# Lab Calculator Suite (PWA)

A modular, installable Progressive Web App (PWA) for clinical and molecular lab calculations, designed to be hosted on GitHub Pages with **Network-First** updates.

## Structure
- `index.html` — Central hub linking to all calculator modules
- `manifest.json` — PWA app metadata
- `sw.js` — Network-first Service Worker
- `icon.png` — 512x512 app icon
- `css/main.css` — Shared responsive styling
- `calculators/realstar-vl.html` — Altona RealStar® Viral Load Calculator

## Deployment on GitHub Pages
1. Upload all files and folders to your GitHub repository root.
2. Go to **Settings → Pages** and deploy from the `main` branch (`/ (root)`).
3. Open the live URL and click **Install App** / **Add to Home Screen**.
